Create and manage places

Starting a place, changing how people find it, and inviting people to it. Only what the signed-in person is allowed to do is shown: the place menu and settings read the permission bits the server sends, and the server still decides. Invites are the only way into invite-only and private places, so creating and revoking them is a first-class screen rather than a menu item.
