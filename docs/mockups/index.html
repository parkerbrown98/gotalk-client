Gotalk client mockups

Static screens for the web, desktop and phone targets, built from the tokens in packages/tokens and the rules in DESIGN.md. They show intent for each phase of the client plan; they are not shipped UI.

Run pnpm build once so packages/tokens/dist/tokens.css exists, then open any file in a browser. Inter loads from Google Fonts.
