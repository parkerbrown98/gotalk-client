Mockups / Phase 1 · Accounts & sessions

Sign in

Sign-in is scoped to the instance picked on the previous screen, so the instance stays visible throughout. Errors say what happened and what to do next; the two states people hit most are a failed login and a throttled one.

Web and desktop

The left column keeps the instance in view so a person never wonders which server they are signing in to. The form column stays 380px wide.

Phone

The instance collapses to a single line under the title. Fields keep their values after an error so a typo costs one correction, not a retype.
